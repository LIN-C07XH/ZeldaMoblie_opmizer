# 原生控制提示与手机事件接入

支持本地校验的 TotK **v1.4.3**，Build ID `277178b7dba1b6d4949a84778d4abc58`。`totk-mobile` 运行游戏，覆盖层保存宿主和客体补丁，通过 `install.sh` 一起安装。

## 游戏内键位

`StaticMsg/GuideKeyIcon` 字符串、A/B/X/Y 等键名表及实际调用点定位出原生图标转换函数 `main+0xba29e0`。名称对照公开 [totk_syms](https://github.com/dt-12345/totk_syms) 的旧版符号，但地址、输出结构和调用方式均在当前镜像重新确认。

在 `main+0xba2a18` 拦截。此处普通按键与选项交换后的 B/X 已汇合，`x19` 是输出，`w1` 是实际键值。输出为 24 字节的借用 UTF-16 文本段：指针、32 位长度、对齐填充、64 位元数据。静态宿主字符串保持有效，元数据使用原生字符串构造器相同的 `-1`；游戏继续负责 TextBox 的设置、测量和绘制。

| 游戏按键 | 键鼠标签 |
| --- | --- |
| A / B / X / Y | E / Shift / Space / LMB |
| L / ZL / R / ZR | Q / MMB / R / RMB |
| Plus / Minus | Enter / Tab |
| 方向上 / 下 / 左 / 右 | 3 / 4 / 2 / 1 |
| 左摇杆及方向 / 按下 | WASD、W/S/A/D / Ctrl |
| 右摇杆 / 按下 | Mouse / V |

`inputGetDevice()` 为键鼠时返回标签，否则继续执行原生图标查找。触屏和外接手柄保留原版语义；屏幕虚拟左摇杆单独标记为触摸。未知键值走原函数。

### 字库与文本容量

原版 `GuideKeyIcon.msbt` 返回 `U+E040` 等私用区图标。图标文本框选用 `External_00.fcpx`，该复合字体原本只包含 `External.bfotf`、名义字号 75。直接返回 ASCII 键名会落到缺字问号；沿用图标字号也会过大。

`script/prepare_ui_fonts.py` 在四套语言字体包中，为这套复合字体增加仅匹配 `U+0020..U+007E` 的文字分支，复用同包已有的 Rodin M 字体，横纵比例均为 0.4（名义 30，再乘原生文本框比例）。原始 External 分支的指标、基线及所有手柄字形保持原样。FCPX 9.3 的相对偏移和 40 字节子字体记录依据当前镜像解析器 `main+0x10e4000` 确认。

共用 UI 包中，32 个布局的 57 个 External 文本框容量扩充到 64 字节，仅修改 UTF-16 缓冲容量，不改原文长度、字体选择、位置和动画。这样可容纳 Shift、Space 等长键名；具体显示宽度仍以实机验收为准。

`prepare_render_resources.py` 与现有渲染堆资源补丁一起生成 `work/romfs-host.bin`。原始 RomFS 保留；字体轮廓文件逐字节保留，只改复合字体描述和文本框容量。源压缩包使用完整 SHA-256 绑定，SARC 保留原有名称/哈希顺序和文件对齐，重打包及 RomFS 写入均验证回读。Mac 默认启动自动准备；自定义 RomFS 和 iOS 资源应同步这份派生文件。

原生 `UIScreen` 帧更新入口 `0x217b838` 提供本次调用中的有效对象。宿主仅识别两个已确认的虚函数表。CtrlGuide 对象在输入模式改变时调用原生重建函数 `0x2147df0`，使用原生最低置位索引规则选择当前最高优先级的 GuideType，刷新已显示的提示。没有从宿主显示线程保存并写回游戏 UI 指针。

GuideKeyIcon 接入覆盖调用该函数的文字图标提示。林克旁边的 DoCommand 十字提示目前保留原版资源，触屏的隐藏与独立交互按钮见下文。其他独立贴图、组合教学大图仍需各自的资源路径，未当作全部 UI 替换。

### 林克旁边的 DoCommand 提示

增加文字子节点的版本已撤回，`DoCommand_00.bflyt` 和 11 个动画文件保持原始字节。新方案在 `Pane::Draw`（`0x1485f0`）接入，Picture/TextBox 的 DrawSelf 入口保持原样。

在实际绘制的 `N_InOut_00` 组中，用直接子节点 `N_MainButton_00` 与 `N_SubButton_00` 确认 DoCommand；这组三个名称的组合在当前 Common 包中唯一。识别与快照更新不依赖屏幕帧回调预先登记。进入有效游玩状态后，替换该界面中 31 个已核对的按键图片/文字叶节点。绘制参数来自本次有效对象：父链必须通向当前 DoCommand RootPane，可见/矩阵就绪位必须符合原生门控。复制 `Pane+0x70` 的世界矩阵位置与缩放、`+0x5a` 的全局透明度，按根布局尺寸归一化后交给 Cocoa/UIKit。宿主层使用系统字体绘制 E、Space、Shift、LMB 等标签，不创建游戏 UI 对象，不调用原生字体或动画构造器。说明文字、捕获效果与按住进度继续走原生路径。

跨线程仅传递数值与文字副本；保存的根地址只用于身份比较，实际访问沿本次活对象的父链进行。宿主叠层每帧续期，停止刷新超过 0.15 秒则恢复原版绘制；单个按键超过 0.075 秒未绘制即过期。未进入游玩、切换手柄、界面更换、未知节点、非叶节点或无效变换均回退原版。键鼠标签以真实可见叶节点为依据，黑板主动作尚未发布时也可替换；手机交互按钮仍要求有效的主动作与文案。根布局资源和层级不变，Mac 使用等比适应映射，iOS 叠层跟随实际“铺满／完整画面”的共享视口计算，安全区只约束触控按钮，不缩窄渲染层。

手机启用 `interact_a` 交互槽位时，在实际 DoCommand 组绘制回调中复制本帧动作后跳过整组绘制，避免原版十字提示与触屏按钮重叠。原生可见位与动画状态均不修改；改用键鼠/实体手柄或禁用交互槽位时直接执行原版绘制。自定义布局删除该槽位则保留原版 HUD。

`inputGetInteractionPrompt()` 提供复制后的主动作按键和本地化 UTF-16 文案，读取同一个实时 DoCommand 黑板，支持 A/B/X/Y/L。消息由原生 `0xba42c0` 按 `LayoutMsg/DoCommand_00` 解析，剥离二进制 MSBT 标签和专用图标字符后交给 UIKit，不把客体字符串指针传给显示线程。无动作、Empty、隐藏、过期 0.3 秒或离开游玩状态时返回无提示。

iOS 的 `interact_a` 常驻右侧固定槽位，实时提示更新文案与实际按键；提示缺失或过期时回退 A 确定，游戏菜单仍可操作。跳跃槽位常驻并共用滑翔操作，原先与交互槽位重叠的独立滑翔默认键改为 R 投掷。标准动作不依赖 PlayerCamera 或 GuideType 的刷新才显示；活动事件只改变颜色与 10% 的视觉放大，按下放大 16%，基础触摸区域与按钮中心不变。动作改变、设备切换和失焦仍释放已按下的实际按键。自定义布局保留可见事件语义；三个历史默认几何布局仅在完全匹配时迁移。

原生宽屏同时接入启动分辨率设置和后续模式切换，逻辑裁切、渲染视口、UI 画布及玩家投影使用相同宽高比。逻辑裁切受固定显示纹理尺寸约束；原生 SetResolution 本身不会扩大显示纹理。宿主呈现保持等比；原生尺寸接入缺失时保留完整画面，不以拉伸兜底。模式在启动后改变需要重新打开应用。

## 手机事件

`main+0x3726538` 对应 `LayoutMsg/CtrlGuide_00` 的屏幕虚函数表。其 `+0x1b8` 是游戏维护的活动 GuideType 位集：原生添加路径写入 `0x2147d2c`，移除路径写入 `0x4cb73c`，类型由 `0x37172d0` 开始的枚举名表核对。在该对象的原生帧更新期间复制位集，不根据按键或鼠标输入猜测状态。

| 布局事件 | 原生 GuideType |
| --- | --- |
| `in_air` | Jump、Parasail、Fall 及快速下落/禁止滑翔伞变体、JumpOff、FastFallLast |
| `climbing` | Climb、ClimbNoJump、ClimbTree |
| `swimming` | Swim |
| `combat` | FirstBattle、SpinAttack |
| `ultrahand` | OneTouchBond、OneTouchBondBow、UltraHand 及抓取/旋转变体、AutoBuilder 变体 |
| `interact` | 实时 DoCommand 黑板的首要提示键为 A，消息存在且不是 Empty，提示没有被要求隐藏 |

这是一套**原生控制提示状态**事件：例如 `combat` 表示游戏启用了战斗控制提示，不等同于附近必定存在敌人；`in_air` 表示原生空中操作指南启用，不是物理接地位。

交互在 `LayoutMsg/DoCommand_00`（虚函数表 `0x3726bc0`）的帧调用内读取，复用原生 `0x2148790` 中相同的类型化黑板接口：

- 黑板单例 GOT：`0x395dff0` → `0x3ad66b0`。
- 获取黑板：`0x3cffe8`，黑板键 `0xca62c947`，输出 16 字节原生句柄。
- 获取首要提示键：`0x980288`，字段 `0x3ffc8e66`，A 的原生枚举哈希为 `0x54dcf7ce`。
- 获取消息：`0x2aab9b4`，字段 `0xd7e9ac3a`。

宿主发布复制后的位集、布尔值与主动作快照，iOS 每帧通过 `inputGetActionEvents()` → `actionDispatchEvents()` 更新现有锚点布局。退出有效游玩状态或超过 0.3 秒未收到相应 UI 帧时，动态事件返回零，常驻事件由布局系统保留。原生提示屏幕完全停止更新时不会沿用过期状态。

## 桥接与验证

独立共享页为 `main+0x3ae4080`，魔数 `ZUI143`、ABI 4、回调指针 `+0x10`。加载器拒绝旧 ABI 或黑板 GOT 不符的模块。补丁校验 Build ID、原指令、键名/类型表及调用点；不接受旧版偏移。

三个跳板保留调用方 GPR、LR、全部 SIMD、NZCV、FPCR、FPSR，跳过 Apple 保留的 x18。绘制跳板用不改变 NZCV 的名称前缀分支过滤普通节点；未接管时重放原始门控指令。原生图标回退路径重新生成被搬移的 ADRP；键鼠图标命中时进入原生函数现有尾声。

C 测试覆盖借用字符串、设备回退、提示重建、事件进入/退出、黑板失败/Empty、过期和桥接校验；Unicorn 执行真实生成的 ARM64 跳板，覆盖回调缺失、原生回退与键鼠成功路径及寄存器保护。没有启动游戏进行操作验收。

诊断日志 `UI_PROMPTS bridge=4` 确认可执行文件与模块版本；每五秒的 status 行区分屏幕帧回调、DoCommand 帧回调、绘制候选、组识别、主动作和宿主标签数量。组识别与首次键盘接管各输出一次日志，避免把单纯加载成功当作功能已经生效。
